# Antique Birthday Letter

React + Vite birthday website.

## Run

```bash
npm install
npm run dev
```

Then open the local Vite URL.

## Add music

Put an MP3 at:

`public/assets/audio/music.mp3`

The first envelope click starts the music at a low volume. The Music button can pause/resume it.

## Customize the message

Edit the text inside `src/main.jsx`, in the `.letter-body` and `.signature` sections.
